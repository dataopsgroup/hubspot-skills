# HubSpot Skills for Claude

Free Claude skills for HubSpot ops. Each one solves a specific problem and outputs something your team can act on immediately.

Built by [Geoff Tucker](https://dataopsgroup.com) — certified HubSpot admin, data operations consultant.

## Skills

| Skill | What it does | Status |
|-------|-------------|--------|
| [Property Audit](property-audit/) | Scans every property in your portal for duplicates, type mismatches, naming inconsistencies, and orphaned fields. Outputs a tabbed workboard grouped by action type. | ✅ Live |

## How to use

1. Open [Claude](https://claude.ai)
2. Copy the `SKILL.md` from any skill folder
3. Paste it as instructions or attach it to your conversation
4. Follow the input instructions in the skill (usually a CSV export from HubSpot)

## What makes these different

These aren't prompts. They're structured skills that produce actionable output — workboards with checkboxes, assignee roles, record counts, and links to the exact HubSpot docs for each fix. The goal is a deliverable your team can divide up and execute, not a report that gets read once.
