# How to run this skill

1. Open [Claude](https://claude.ai)
2. Attach the `SKILL.md` file to your conversation
3. Export your properties from HubSpot: **Settings → Properties → Export all**
4. Attach the CSV to the same conversation
5. Send this prompt:

```
Run the HubSpot Property Audit skill on the attached CSV. Output the interactive HTML report with tabbed workboard.
```

That's it. Claude will analyze your properties and generate a report you can open in any browser.
