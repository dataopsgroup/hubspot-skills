Every HubSpot portal I've audited has the same problem: property rot.

Duplicate fields splitting data between them. Revenue stored as text so you can't report on it. 40+ custom properties that nobody documented when they created them.

You don't notice it until a report is wrong or an automation breaks. By then it's a mess.

So I built a Claude skill that audits every property in your portal in about 90 seconds.

Here's how it works:

→ Export your properties from HubSpot (Settings → Properties → Export all)
→ Drop the CSV into Claude with this skill attached
→ It scans for duplicates, type mismatches, naming inconsistencies, undocumented fields, and orphaned integration properties
→ Then it outputs a tabbed workboard — one tab per action type, every item has a checkbox, a record count, and a link to the exact HubSpot doc for how to fix it

The tabs are workstreams, not severity levels. Merge Duplicates goes to your ops lead. Fix Data Types goes to a developer. Archive Orphans goes to your admin. Your team can divide and conquer instead of dumping the whole list on one person.

Grab the skill free: https://github.com/dataopsgroup/hubspot-skills/tree/main/property-audit
